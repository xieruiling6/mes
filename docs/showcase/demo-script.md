# 3 分钟演示脚本（对 HR / 非技术面试官）

目标：让对方在 3 分钟内明白「这系统是干什么的、能跑、你想得清楚」，而不是看完 11 个菜单。

## 演示前 10 分钟检查清单

- [ ] MySQL 已建库并执行 `docs/sql/init.sql`，管理员账号可登录
- [ ] 后端 `cd backend && mvn spring-boot:run`，`curl localhost:8080/api/health` 返回 200
- [ ] 前端 `cd frontend && npm run dev`，浏览器打开 5173 并**保持登录态**
- [ ] 演示数据已预置：≥2 个产品、1 个已确认订单、1 个可报工的「生产中」工单
- [ ] 浏览器缩放 100%、关掉无关标签页、关掉通知
- [ ] **兜底**：全程录屏一份（OBS/系统录屏），现场跑不起来就放录像
- [ ] 不要展示 `.env`、终端里的数据库密码、IDE 里的密钥文件

## 讲稿（按秒走）

**0:00–0:20 定位**
> 「这是一个工厂用的管理系统，叫 MES。简单说，就是一张订单从接下来、排产、开工、报工、质检到完工，全程在一个系统里走完，而不是靠 Excel 和纸质单。我独立做了前后端。」

**0:20–0:50 先讲权限，制造「这就是真系统」的印象**
- 用管理员登录 → 进「系统管理」，展示用户、角色、权限配置
- 一句话点题：「菜单是按权限显示的，但更关键的是后端也拦，操作员直接调接口会被拒绝。」
- 如果时间紧，这步可以合并到结尾

**0:50–1:40 走一遍主链路（这是核心，讲业务不讲技术）**
1. **产品管理**：新建一个产品「GQ-450 减速机」，设编码和计量单位 → 「所有单据都引用主数据，编码重复数据库会拦。」
2. **生产订单**：客户下 500 台 → 建订单 → 确认 → 「确认后就不能随便改了，改要带版本号，两个人同时改只有一个人成功。」
3. **生产计划**：排开始/结束日期，数量必须等于订单量 → 发布。
4. **生产工单**：从计划开工单 → 下发 → 开工 → 「一张计划只能开一张工单，数量必须相等，这是工厂最容易乱的地方。」

**1:40–2:10 报工环节，演一次「被系统拦住」**
- 进「生产报工」，正常报 200 件合格 + 5 件报废 → 成功
- 再报一次 400 件（超过剩余量）→ 页面提示失败
- 立刻补一句：「不是弹窗提醒一下就算了，是后端在事务里锁住工单算完才拒绝的。两个人同时报最后 100 件，只会有一笔成功。」

**2:10–2:35 质量与设备（各 10 秒，点到为止）**
- 质检：对刚报的工单做检验，检验数不能超过合格报工数；不合格的登记处置方式
- 设备：打开一台设备的维修记录 → 「设备状态是人工维护的，我没有假装它是传感器采集的数据。」

**2:35–3:00 看板收尾**
- 进「生产统计」：切日期范围、按产品筛选 → 「这里每个数字都能下钻到报工明细，数量和明细是对得上的；刚才作废的报工不算进来。」
- 最后一句：「代码、设计文档、测试报告都在仓库里，73 项自动化测试是跑通的。」

## 千万不要做

- ❌ 从技术栈开始念（「我用了 Spring Boot、MyBatis……」）——HR 记不住，也不关心
- ❌ 逐个菜单点一遍——3 分钟会变成 8 分钟，且没有记忆点
- ❌ 现场第一次启动环境
- ❌ 说「这是个练习项目 / 跟着教程做的」——换成「这是我按真实工厂流程设计的项目」
- ❌ 发源码压缩包代替演示；发链接 + 视频就够了
- ❌ 夸大：没做的（比如真实设备采集、多租户、微服务）不要说做了，被追问一句就露馅

## 被追问时的 30 秒回答

| 问题 | 回答要点 |
| --- | --- |
| 「这是你一个人做的？」 | 说明分工：需求文档、数据库设计、后端接口、前端页面、验收测试分别谁做；即使部分协作也讲清楚边界 |
| 「为什么不用 JWT？」 | 内部管理系统，浏览器场景用 Session + HttpOnly Cookie 更简单安全，配合 CSRF Token，退出即失效 |
| 「怎么保证数据准确？」 | 三层：数据库唯一约束、服务端事务内校验、操作日志留痕；数量类校验全部在服务端 |
| 「测试怎么做的？」 | JUnit 单测 + 数据库集成测试覆盖完整链路 + 46 项接口验收 + 浏览器自动化验收，验收报告里记录了发现并修复的 6 个缺陷 |
| 「遇到最大的困难？」 | 推荐讲并发报工：一开始只在前端限制，后来用两个并发请求复现出超报，改成行锁 + 事务内汇总，并补了并发用例 |
| 「下一步做什么？」 | Flyway 自动迁移、报表导出、部署编排（Docker + HTTPS）；诚实说「还没做」比硬编好 |
